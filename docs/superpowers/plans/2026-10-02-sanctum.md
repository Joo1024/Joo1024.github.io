# Sanctum Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 实现可直接运行和由 GitHub Pages 发布的 Sanctum。
**Architecture:** Hugo 原生模板从 Markdown 构建所有页面；CSS 控制排版，JS 仅提供主题选择。数据文件定义栏目，taxonomy 与时间索引自动生成。
**Tech Stack:** Hugo 0.147.9、HTML、CSS、原生 JS、Python 标准库验收。
**Spec:** docs/superpowers/specs/2026-10-02-sanctum-design.md

## Global Constraints

- 站点名 Sanctum；九栏目 Now / Path / Reflection / Practice / Making / Reading / Journey / Notes / Yearly。
- 无数据库、商业平台绑定、分析追踪、第三方字体或运行时 CDN。
- 原始发布日期保留，观点变化追加后记；示例文章明确标注。
- 手机和桌面可读；系统 / 浅色 / 深色；无 JS 仍能读。
- 不自动推送此次重构；保留现有 checkout。

## Review Focus

- 子路径部署：全部本地链接、RSS 和资源在 /sanctum/ 下仍有效。
- 缺省 metadata：缺少可选 tags / later_notes 仍能构建；无效 status 明确失败。
- 中文标签：编码后的链接实际可解析；脚注/目录锚点存在。
- 时间变化：lastmod 不改变原始年份和相邻文章顺序；后记进入订阅。
- JS 禁用或 localStorage 不可用：页面可读且主题仍跟随系统。
