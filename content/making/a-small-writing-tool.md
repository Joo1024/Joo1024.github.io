## 做出了什么

一个从 Markdown 生成的静态书房。正文存放在普通文本文件里，分类、标签和时间索引自动生成，发布由 Git 完成。

它不需要数据库，也没有后台。把整个目录复制走，文字仍然完整。

## 为什么这样做

写作之前需要做的事越少，留下一个念头就越容易。理想中的步骤只有三个：打开文件，写下文字，提交。

```text
一个原始念头
    ↓
整理为 Markdown
    ↓
content/ 对应栏目
    ↓
Git commit → Git push → 静态发布
```
